# 麻雀点数計算 完全版（4人麻雀）

GitHub Pagesへそのまま配置できる4人麻雀版。三人麻雀は未実装。

## 主な機能

- 初期画面：点数計算 / 点数表 / 役一覧
- ⚙ ルール設定の一括管理（喰いタン、切り上げ満貫、数え役満、ダブル役満、連風牌4符、赤ドラ、裏ドラ）
- 簡易計算（従来の手動符計算）
- 手牌入力をポップアップ化
- ポン・チー・暗槓・大明槓・加槓の副露入力
- 鳴いた牌の横向き表示と副露編集・削除
- 和了牌選択
- リーチ / 一発 / 嶺上開花 / 槍槓 / 海底 / 河底 / 天和 / 地和
- ドラ / 赤ドラ / 裏ドラ
- 牌姿分解を複数生成し、役・飜・符で最も高い候補を採用
- 主要通常役・役満の自動判定
- 七対子25符、平和ツモ20符、暗刻・明刻・暗槓・明槓の符計算
- 待ち（両面・辺張・嵌張・単騎・シャンポン）の判定
- 親子・ロン / ツモの点数計算
- 20/25/30/.../110符 × 1～5飜の点数表
- 満貫・跳満・倍満・三倍満・数え役満・役満の表
- 役一覧（門前/鳴き/喰い下がり/参考出現率）
- PWA / Service Worker

## GitHub Pagesへの配置

ZIPを展開し、**中にあるファイルとフォルダをリポジトリの最上階層にアップロード**する。

```text
score-calculation/
├─ index.html
├─ style.css
├─ app.js
├─ manifest.json
├─ sw.js
├─ README.md
├─ icon/
├─ title/
└─ tiles/
```

`麻雀点数計算_完全版_4麻` のような外側フォルダを作って、その中身をもう一階層に入れないこと。

## キャッシュについて

Service Workerのキャッシュ名は `mahjong-4p-complete-v5`。更新時は古いキャッシュを削除して新しい版を使用する。

## 役の出現率

役一覧の出現率は4人打ちの公開統計を基にした参考値で、ルール・集計期間・対局者層によって変動する。アプリ内では「目安」として表示する。
